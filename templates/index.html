About This Project

This project demonstrates the application of permutations and combinations in password security.

Mathematical Formula

Total Possibilities = Character Set Size ^ Length

Example

A 4-digit PIN has 10 possible digits for each position.

10 × 10 × 10 × 10 = 10,000 possibilities.
